Content decisions

  1. Confidence sits in the header. Clicking it shows the reasons, so 92% is never an unexplained number.
  2. Meta stays as one plain row. It's for context only.
  3. Recommendation is a specific action plus a deadline, with the questions it's based on. If a recommendation can't cite a question, don't show it.
  4. 4 parameters: Safety, Readiness, Condition, Compliance. Each has a status word, one line of reasoning and the questions behind it. Readiness cites a work order because the work order is what unblocks it.
  5. Overview uses your stat row. The 127-question bar shows completeness, and time, photos and linked work orders sit in one strip. The bullets stay short: risk, impact, action.
  6. Defects & Findings lists every finding with its severity, question, inspector quote, photos and the work order it led to. A finding with no work order gets a Create button.
